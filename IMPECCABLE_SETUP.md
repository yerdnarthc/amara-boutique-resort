## Use in this project

Read PROJECT_PLAN.md and AGENTS.md first. Use the Impeccable skill for UI/UX, aesthetics, layout, typography, accessibility, responsive behavior, error/empty states, and interface copy. Preserve the selected Amara identity, Anthropic brand palette/typography, C#/Blazor stack, five-screen scope, and timed-exam priorities. User requirements take precedence over generic design warnings.

Avoid repetitive template layouts, arbitrary decoration, empty marketing phrases, invented reviews/awards, and unsupported claims about tourism services. Make room descriptions, prices, inclusions, booking labels, validation errors, and confirmation copy concrete. Mock facts must be identifiable as demonstration content.

Before the first UI implementation, complete Impeccable's init flow using the existing project plan as known context, then follow its new-work guidance. PRODUCT.md and DESIGN.md have not been created by this installation; PROJECT_PLAN.md remains the current project reference.
