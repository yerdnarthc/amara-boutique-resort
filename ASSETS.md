## Fonts

Fonts are served locally; visitors do not need to install them or connect to an external font service.

- Poppins Regular and SemiBold: https://github.com/google/fonts/tree/main/ofl/poppins
- Lora variable font: https://github.com/google/fonts/tree/main/ofl/lora
- Licenses: wwwroot/fonts/Poppins-OFL.txt and wwwroot/fonts/Lora-OFL.txt (SIL Open Font License).
- CSS fallbacks: Arial for headings/UI and Georgia for body copy.

## Icons and favicon

- Interface icons use MudBlazor's Material icon constants, included through the pinned MudBlazor NuGet dependency.
- wwwroot/favicon.svg is a simple original lettermark using the project palette.
